# 🏃 Escape Ideas — living notes doc

Every escape method needs a counter you can build or manage — **that back-and-forth IS the game.** Dump every idea here the moment you think of it so nothing gets lost. Rough is fine; tidy later.

## Core set (from the game plan)

| 🏃 How they try to escape | 🛡️ How you stop it | Status |
|---|---|---|
| Digging tunnels from cells & showers | Floor sensors, concrete foundations, guard patrols, routine cell searches | 💡 idea |
| Smuggling contraband (keycards, tools, files) | Metal detectors, sniffer dogs, searches at intake & after visits | 💡 idea |
| Climbing / cutting the fence | High walls, razor wire, watchtowers, floodlights, sensor fences | 💡 idea |
| Starting a riot as a distraction | Keep needs met, enough guards, riot squad, the big red Lockdown button | 💡 idea |
| Hiding in work crews / laundry / deliveries | Headcounts, exit checkpoints, search-on-leave | 💡 idea |
| Jumping a lone guard | Patrol in pairs, camera coverage, panic buttons | 💡 idea |

**Status legend:** 💡 idea → 🔨 building → ✅ in game

> Phase 3 starts with **ONE** of these (fence-climbing is the suggested first pick), gets it fun, then adds a second (tunnels or contraband). Don't build all six at once.
