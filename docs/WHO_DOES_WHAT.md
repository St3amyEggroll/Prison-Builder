# 🤝 Who does what — Claude & you, phase by phase

You have zero coding experience — that's fine, because **Claude writes 100% of the code.** Your jobs are the ones that need a human with a Roblox account: installing Studio, playtesting, rounding up friends, publishing, and telling Claude what's fun and what's confusing.

## 🔁 The rhythm (every phase works like this)

1. **Claude codes** everything in this repo and builds it into a single game file: `Lockdown.rbxlx`.
2. **You download that file** from GitHub and double-click it — it opens in Roblox Studio, ready to play. No tools, no code.
3. **You play it** (and get friends to) and report back in plain English — "the button's tiny on my phone", "I got bored after 2 minutes", "the escape felt unfair".
4. **Claude fixes and improves**, ticks the boxes in [ROADMAP.md](ROADMAP.md), and the loop repeats.

> **The honest limits:** Claude can't run Roblox, publish to your account, create gamepasses, or test on a real phone. Those are always yours — your playtesting is the steering wheel for the whole project.

---

## Phase 0 — Setup *(an afternoon, not a week)*

**Claude:** Sets up the code project in this repo. Writes `SETUP.md` — a click-by-click guide (install Studio, open the game file, press Play, publish). Builds a tiny hello-world place: a button that gives +$10.

**You:** Install Roblox Studio, make a Roblox account + group, open Claude's file, press Play, tap the button, watch the money go up. That one moment proves the whole pipeline works.

> The original Phase 0 said "do tutorials & learn DataStores" — you can skip the studying. Claude explains every script in plain English as we go, so you learn by osmosis instead of homework.

## Phase 1 — MVP: the core money loop 🚀

**Claude:** The whole MVP — plot with a buy-a-cell button; each cell spawns a lightweight custom-rig inmate that pays cash on a timer; cash counter UI; buy more cells; save/load so progress survives leaving; works on touch screens from day one.

**You:** The fun test — is buying cells satisfying *by itself*? Get one friend to play. Watch what confuses them. Report back.

## Phase 2 — Needs & staff foundation

**Claude:** Food + Sleep meters; kitchen/canteen and beds that fill them; hiring a Cook and a Guard with daily wages; soft recoverable unrest; the remaining needs (hygiene, recreation, safety) once the first two feel good.

**You:** Balance feedback — does money feel fair? Do needs feel like an interesting puzzle or an annoying chore?

## Phase 3 — Escape & security ❤ *the heart*

**Claude:** AI inmates that attempt fence-climb escapes; the counters (walls, a patrolling guard, a camera); alarm + the big red Lockdown button + recapture; the Escape-Proof rating on screen; a second escape type (tunnels or contraband) once the first is fun.

**You:** Try to *lose* on purpose — under-build security and see if escapes are exciting instead of frustrating. This is where the game's soul gets tuned, and only a player can feel it.

## Phase 4 — Real depth: tiers, contraband, automation, prestige

**Claude:** Security tiers (Min → Med → Max) with craftier, higher-paying inmates; contraband + metal detectors + sniffer dogs; a branching research tree; first automation (patrol routes, auto-search checkpoints); prestige "New Posting" with permanent perks.

**You:** Longer play sessions. Decide priorities: which theme first? Which automation feels best? What would keep *you* playing for a week?

## Phase 5 — Roblox magic: Break Out mode 🚀 *the ace*

**Claude:** The hardest engineering — players spawning into a prison as inmates, first-person, live; co-op building & guarding with friends; attempting other players' prisons; the global Escape-Proof leaderboard.

**You:** This phase needs real humans. Round up friends for multiplayer tests — one plays warden, one tries to break out. Tell Claude who had more fun and why.

## Phase 6 — Monetize & launch 🚀

**Claude:** All the gamepass & dev-product code (cosmetic-first!); a mobile UI polish pass; the game description leading with the "break out of my prison" hook; specs/drafts for the icon and thumbnail.

**You (account-owner-only tasks):** Create the gamepasses and dev products on the Roblox website; upload the icon & thumbnail; playtest on your actual phone; click **Publish**. You made a game! 🎉

## Phase 7 — Grow it

**Claude:** A redeem-codes system; event content; new escape types & counters; bug fixes from player reports; reading the analytics.

**You:** Community — make the Roblox group + Discord; watch how strangers play; collect complaints and ideas; decide together what ships next.
